# P0-04 — Remote OK

> Founder: Pieter Levels  
> Model: Job board / marketplace / SEO  
> Research date: 2026-09-28

## 一页摘要
Remote OK 是 Pieter Levels 商业上最强的非 AI 产品之一。早期它只是 Nomad List 的“remote jobs”衍生需求，后来发展成独立远程招聘平台。

Pieter 在 2017 年披露 Remote OK 约 $12K/月，2018 年约 $20K/月。2022 的访谈中他称 Remote OK 约 $1.6M/year。2025 Stripe 访谈中 John Collison 引用 Remote OK 累计/年化约 $3.4M revenue 规模。

## Who pays
真正付费方主要是公司 / recruiter：
- 发布远程职位；
- premium placement；
- 更高曝光。

求职者侧基本免费，形成典型“供给免费、需求方付费”的 job board。

## Distribution
### SEO
Remote jobs 本身具有巨大关键词需求：
- remote developer jobs
- remote design jobs
- remote marketing jobs
- company/job/location pages

大量结构化页面形成长尾流量。

### Cross-product
早期与 Nomad List 用户高度重叠：
数字游民需要远程工作，因此 Nomad List 带来天然初始 demand。

### Founder audience
Pieter 持续公开收入与远程工作趋势，增强品牌曝光。

## Why job boards can be high-margin
平台不需要：
- 为每个职位人工交付服务；
- 处理复杂业务流程；
- 按座席支持大量终端用户。

价值来自：
- audience；
- distribution；
- trust；
- ranking / filtering。

这使成熟 job board 可以具有极高边际利润。

## Key decisions
1. 从已有 audience 的 adjacent need 出发，而不是冷启动双边市场。
2. 让求职者免费，向 employer 收钱。
3. 大量 SEO landing pages 持续积累。
4. 产品长期保持简单，避免扩成完整 ATS。

## 已验证事实
- Remote OK 是 Pieter 的长期成功项目；
- 2017/2018 已有五位数月收入；
- 2022 Pieter 自述约 $1.6M/year；
- Stripe 2025 访谈引用更高收入规模。

## 外部推断
Remote OK 的核心 moat 很可能不是 software，而是：
- domain authority；
- candidate traffic；
- employer recognition；
- remote-work category brand。

因此复制 UI 很容易，复制 demand liquidity 很难。

## 未知
- 最新独立 ARR / annual revenue；
- employer repeat rate；
- paid job average order value；
- SEO 占 acquisition 比例；
- 与大型平台 LinkedIn / Indeed 的流量重叠程度。

## 自己判断的问题
1. Job board 真正的产品到底是软件，还是 audience？
2. 什么 niche 能重复 Remote OK 的“免费流量 + B2B 付费”结构？
3. 双边市场冷启动时，是否最好从已有单边 audience 延伸？
