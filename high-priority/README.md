## 研究标准

- 研究深度优先，篇幅其次
- 尽量覆盖 Company / Founder / Team / Funding
- Revenue / MRR / ARR / Users 时间序列
- Product / ICP / Use Cases
- Pricing 与定价历史
- 转化证据、switching reasons、用户抱怨
- Distribution：SEO / Community / Product Hunt / Word of Mouth / Marketplace / Sales / Ads / AI Search
- 创始人访谈与关键经营决策
- 团队效率、成本结构、商业模式演进
- 严格区分：已验证事实 / 创始人自述 / 外部推断 / 未知
- 对来源质量存在争议的数据明确降级，不把二手流传数字当成当前事实

7. **FeedbackPanda** — 看 narrow vertical SaaS
8. **Plausible + Fathom** — 同市场双案例对照

## 第一轮横向比较维度

读每篇时可以只记 8 个字段：

| 维度 | 要问的问题 |
|---|---|
| Problem | 用户到底在为什么付钱？ |
| ICP | 用户是否足够集中、容易找到？ |
| Wedge | 为什么不继续用原来的方案？ |
| Pricing | 按什么收费，为什么？ |
| Distribution | 第一批和后续用户分别从哪来？ |
| Retention | 为什么会留下/复购？ |
| Team | 多少人支撑多少收入？ |
| Moat | 去掉 founder 光环后还剩什么？ |

完成这 15 篇后，不建议立即继续加样本数量；先做一次横向模式提炼，会比继续看第 16～30 家更有价值。
