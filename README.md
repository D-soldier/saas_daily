# SaaS Daily

用可验证信息持续训练 SaaS 商业判断。

## 研究原则

- **研究深度优先，阅读时长其次**：报告可以是约 10 分钟甚至更长，不为缩短篇幅牺牲关键证据
- 区分：已验证事实 / 创始人或公司自述 / 外部推断 / 未知
- 不把推断或二手流传数字写成当前事实
- 不替读者判断“这个生意好不好”
- 尽量补齐收入、团队、用户、定价、获客、迁移原因和关键经营决策
- 只有充分检索后仍缺证据的内容才进入“未知”
