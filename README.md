# SaaS Daily

每天研究一个 SaaS，用可验证信息训练商业判断。

## 研究原则

- 区分：已验证事实 / 创始人或公司自述 / 外部推断 / 未知
- 不把推断写成事实
- 不替读者判断“这个生意好不好”
- 每篇控制在 3–5 分钟阅读量
- 详细证据可以保留，但正文优先可读性
